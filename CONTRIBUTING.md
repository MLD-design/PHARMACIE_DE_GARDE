# Conventions de contribution — PharmaGarde Sénégal

- **Branches** : `main` (protégée), `develop` (intégration), branches de travail `feat/*`, `fix/*`, `docs/*`, `chore/*`.
- **Commits** : format `type(scope): description courte` (exemple : `chore(s0-7): ajout environnement et workflow ci`).
- **Revue** : Pull Request obligatoire avec validation du workflow GitHub Actions.
