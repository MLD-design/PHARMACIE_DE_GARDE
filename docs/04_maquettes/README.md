# Maquettes UI / Wireframes — Sprint 0 (`S0-6`)

**Projet :** Plateforme de gestion des pharmacies de garde (`PharmaGarde`)  
**Référence Sprint :** Sprint 0 — Tâche `S0-6` (*Concevoir les maquettes / wireframes*)  
**Stack de référence :** React + Vite + Tailwind CSS · Leaflet + OpenStreetMap  

## Objectif
Illustrer les principaux parcours utilisateurs du MVP avant le démarrage de l'implémentation applicative :
1. **Parcours Citoyen (`US-01`, `US-02`, `US-03`) :** Recherche par zone ou géolocalisation GPS, filtrage des officines de garde, consultation sur carte interactive (Leaflet / OpenStreetMap), accès à l'itinéraire/appel et signalement d'anomalie.
2. **Espace Pharmacien (`US-04`, `US-05`, `US-06`) :** Gestion du statut d'ouverture immédiate, déclaration et suivi des créneaux de garde (en cours et programmés).
3. **Espace Administrateur (`US-07`, `US-08`) :** Suivi des indicateurs clés, validation des inscriptions de pharmacies et traitement des signalements citoyens.
